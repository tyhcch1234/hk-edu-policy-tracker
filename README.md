# 香港教育政策 2023–2026：承諾與落實的距離

以香港特區政府四份《施政報告》（2023、2024、2025、2026）的教育篇章為底稿，逐項追蹤 30 項有明確時限的教育承諾，對照公開落實證據，計算加權完成度，並分析七大政策支柱與關鍵指標走勢。

## 內容

- **五個核心判斷** — 硬指標交付快、軟指標幾無進展
- **政策時間軸** — 2023 年宣布至 2026 年落地
- **七大政策支柱** — 數字教育・國際樞紐・職專・國民教育・教師・學生支援・學校規劃
- **完成度記分卡** — 30 項承諾按狀態與主題聚合（加權完成度 72/100）
- **逐項追蹤表** — 每項的承諾內容、時限、狀態、落實證據
- **關鍵指標** — 小學生人數、小一淨減班、非本地生上限、教師流失率
- **落差、風險與建議** — 5 項明確落差、3 個風險、5 項建議
- **方法與資料來源** — 評分準則、限制、16 項資料來源

## 技術

純靜態網頁，零外部依賴：

- `index.html` — 內容與結構
- `assets/style.css` — 樣式（響應式、支援列印）
- `assets/app.js` — 政策資料集、SVG 圖表（無圖表庫）、表格渲染、導覽高亮

圖表全部以原生 SVG 繪製，不需 CDN、不需建置步驟。

## 評分方法

| 狀態 | 分數 |
|---|---|
| 已落實 | 1.0 |
| 部分落實／進行中 | 0.6 |
| 延後／需調整 | 0.25 |
| 待觀察（未到期） | 0（不計入） |

完成度 = 該主題總分 ÷ 項數 × 100。

## 限制

- 2026 年《施政報告》屬新周期，措施多未到期，只列觀察、不計分。
- 「部分落實」的界線具判斷成分；部分措施無公開量化進度。
- 本文只追蹤「承諾是否交付」，不評估政策成效。
- 各主題樣本量由 1 至 10 項不等，主題分數不宜直接互比。
